# CITS4012-Project
CITS4012 Natural Language Processing Group Project — MultiRC Question Answering

> [!NOTE]  
> **Development Workflow:** All interactive development is conducted in `notebook.py` using [Marimo](https://marimo.io/). The Jupyter notebook `notebook.ipynb` is **automatically constructed and sanitized** via a GitHub Actions workflow (`.github/workflows/marimoConverter.yml`) on every push to the `main` branch. Do not edit `notebook.ipynb` directly; make all changes in `notebook.py`.
